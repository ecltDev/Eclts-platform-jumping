# Eclts_plantfrom_jumping
Godot Game Dev repository Use in Git

## 杂项
> 请注意:
该项目仅为 **学习Godot用途** 暂时还没有达到发布的水平
 - 其他更新事项详见TODO.md
 - 给XMX的提示(如果能看到):如果发现无法换行 重复以下步骤即可
	1. 选中 **任意** 一段文本
	2. 打开输入法 **文字编辑** 功能
	3. 点击中间的 **取消选择** 按钮
	4. 在文本编辑界面 **向左** 移动光标

请不要上传 **.godot** 文件 这是决定 **编辑器界面状态** 的文件(*对游戏并无关联*)
也不要上传 **.editorconfig** 理由同上
 - 均已在`.gitignore`忽略

## 键位映射
|#序号|输入按键|命名全称|动作|
|:---|:------|:------|:--|
|1|J/Space|Jump|向上跳跃|
|2|O|Operat|在交互区域内交互|
|3|R|Respawn|移动玩家到重生点|
|4|A/Left|MovePlayerLeft|向左移动玩家|
|5|D/Right|MovePlayerRight|向右移动玩家|
